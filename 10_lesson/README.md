Домашнее задание №10: Добавление к домашнему заданию №7 Allure.

Проект содержит реализацию автоматических тестов для двух веб-приложений:
1. Калькулятор с задержкой — тестирование арифметической операции с установленной задержкой.
2. Интернет-магазин SauceDemo — тестирование процесса оформления заказа и проверки итоговой суммы.

 Реализация проекта:
1. Полная документация всех классов и методов с указанием типов параметров и возвращаемых значений
2. Интеграция с **Allure** для формирования детальных отчетов о тестировании
3. Разметка шагов и проверок с использованием `with allure.step()`
4. Декораторы Allure: `@allure.title`, `@allure.description`, `@allure.feature`, `@allure.severity`
5. Поддержка браузеров Chrome и Firefox через параметр командной строки

Требования к окружению:
- Python 3.14.2
- Java 11 или выше (требуется для Allure)
- Google Chrome Версия: 146.0.7680.165 (официальная сборка) (64 бит)  и/или Mozilla Firefox 140.9.0esr (64-разрядный)
- Windows 11 Домашняя
